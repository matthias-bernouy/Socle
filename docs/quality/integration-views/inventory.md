## Créations et navigation particulières

- Commerce : produit, offre, marque, catégorie, métadonnée, état de raquette, état de workflow et transition utilisent actuellement une sélection de fiche vide.
- Consent : `newConsentContext` crée une politique via le service de management ; la publication des versions reste une opération métier explicite.
- Forms : `newFormDetail` crée un formulaire ; `createSection` et `createQuestion` créent les enfants via des endpoints dédiés et des références de parent.
- User Account : création d’une définition de champ ; la fiche utilisateur correspond à un utilisateur existant, pas à une création arbitraire de compte depuis ce formulaire.
- Emailer : création d’un template ; envoyer un email de test est une opération indépendante.
- Delivery : `openSettings` ouvre un singleton. Son utilisation du même mécanisme de sélection que la création ne doit pas être reproduite comme une vraie création.
- Les lookups créateurs et les contrôles médias ajoutent leurs propres opérations ; ils sont inclus dans la liste des endpoints ci-dessous.
